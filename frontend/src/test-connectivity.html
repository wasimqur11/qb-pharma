QB Pharma - Backend Connectivity Test

Manual Connectivity Tests

Instructions for Full Testing

  1. Both frontend (http://localhost:5173) and backend (http://localhost:3001) are currently running
  2. Open the main application in another tab: http://localhost:5173
  3. Look for the connectivity indicator (small dot/icon) in the top header next to notifications
  4. When both servers are running, you should see a green dot indicating "Connected"
  5. To test disconnection scenarios:
    • Stop the backend server to simulate server down
    • Disconnect your internet to simulate network issues
    • Change the API URL to simulate wrong server address
  6. You should see appropriate alerts and the connectivity indicator changing colors
